# solutions config

> Machine-specific settings for the `solutions` planner on your own work laptop. Copy this file to `config.md` in the same folder and fill it in. Not tracked in git. (Teammates use the `config.example.md` from the shared `solutions-workflows` repo instead.)

- **vault_path:** ~/path/to/your/work/vault
- **tickets_path:** <vault_path>/raw/tickets
- **domains:** solutions, csp, onboard, rate-card, code, database, meta, obsidian
- **sources:** manual, linear, helpscout
